Как считается

Q = ρ · cₚ · G · |T₁ − T₂| / 3600

G — объёмный расход в м³/ч, ρ — плотность в кг/м³, cₚ — удельная теплоёмкость в кДж/(кг·К). Результат показывает величину передаваемой тепловой мощности в кВт. Объёмный расход и свойства жидкости отнесены к средней температуре контура.

Для воды и дистиллята приняты свойства чистой жидкой воды. Плотность и теплоёмкость определяются по температуре в диапазоне 0–100 °C. Данные IAPWS.

Концентрация 30 % по массе соответствует 30 кг гликоля и 70 кг воды на 100 кг раствора. Модель охватывает растворы от 0 до 60 % по массе, от температуры начала кристаллизации до 100 °C. Свойства растворов по Мелиндеру в CoolProp.

Для топлива и минеральных масел подставлены типовые свойства жидкой фазы при 0–70 °C. Плотность пересчитывается от опорной температуры, теплоёмкость оценивается по корреляции Краго. Для конкретной партии можно выбрать «Свои свойства (по паспорту)». Корреляция теплоёмкости NBS · Температурные поправки Veeder-Root.

Для Therminol 66 свойства жидкой фазы берутся из таблицы изготовителя с интерполяцией по температуре. Диапазон расчёта от −3 до 345 °C. Технические данные Eastman.

Для Тп-22С в качестве примера принята плотность 870 кг/м³ при 20 °C. Паспорт ЛУКОЙЛ Тп-22С, марка 2.

Для класса вязкости ISO VG 46 в качестве примера принята плотность 866,7 кг/м³ при 15,6 °C. Данные Mobil DTE 25 Ultra.

Паспортные значения плотности и удельной теплоёмкости относятся к выбранной однофазной жидкости при средней рабочей температуре.
